Agito InsurTech Modernization

How a sole Design Systems Architect dismantled five years of outsourced agency failures at a 250-engineer insurtech company—establishing an Ant Design v5 Control System to govern an initial 68-screen foundation and scale across a 350+ screen multi-wave enterprise roadmap.

35% National Market Share

350+ Multi-Wave Scope

01. The 3-Agency Inheritance

Agito powers core transactional operations for 35% of Turkey’s private pension and insurance sector. When I joined as the company’s first Lead Design Systems Architect, the organization comprised 250 employees—almost entirely backend database developers, actuarial analysts, and account executives—with zero centralized design infrastructure.

Over the preceding five years, Agito had contracted three consecutive external design agencies. All three attempts failed identically:

  • Agencies produced subjective, Dribbble-style mockups tailored to isolated Product Owner sprint requests.
  • Deliverables lacked token architecture, reusable layout floorplans, or actuarial edge-case awareness.
  • Frontend developers wrote thousands of lines of fragile, screen-specific CSS that collapsed under regulatory workflows.

02. The Inverted Waterfall & The UX Readiness Gate

During my initial quarter, leadership pushed for an inverted waterfall: "Design all buttons, menus, and component libraries first so the Board can approve visual polish, then we will wire the business logic."

Simultaneously, four Product Owners submitted ad-hoc sprint requests without validated user journeys or problem statements. To establish governance, I introduced the UX Readiness Gate. Production commenced only when three invariants were delivered:

  1. User Persona & Problem Bound: Exactly who is operating the interface (Actuary, Collector, Claims Handler) and what concrete business friction is being resolved.
  2. End-to-End Flow Blueprint: Current versus target journey mapped across module boundaries before creating Figma frames.
  3. Actuarial Invariants: Immutable business rules, distribution logic, and regulatory constraints defined up front.

Requests lacking these invariants were rejected at the gate, eliminating over 70% of speculative screen churn.

03. Month 7: Test Automation Breakdown

In Month 7, frontend teams attempted to write automated QA test suites against screens implemented from legacy agency files. The code broke down completely. Because agency drawings forced developers to create bespoke DOM hierarchies for each view, automated selectors failed on every minor release.

In an executive review with the CTO and Engineering Directors, I presented a side-by-side technical comparison:

Metric / Layer Outsourced Agency Deliverables Ant Design v5 Control System
Layout Topologies Arbitrary, non-standard layout geometries per screen 4 Universal Floorplans (100vh Viewport Fitting)
Modality Patterns Nested conditional modals breaking state machines 2-Row Grid Drawers & atomic 1–4 input dialogs
CSS Discipline Thousands of lines of bespoke overrides Zero custom CSS (`agitoTheme` token compiler)
QA Automation Fragile DOM; automated selectors fail continuously Deterministic DOM structure; 100% test automation pass rate

The technical proof resolved the debate. Leadership terminated external agency contracts and committed 100% of frontend modernization to the internal Control Architecture.

The Zero-Marginal-Cost Architecture

In legacy agency paradigms, adding 300 screens requires hiring dozens of contract designers; cost scales linearly while technical debt compounds exponentially. In Agito’s Control Architecture, the system operates on a zero-marginal-cost curve:

Dimension Agency Model (Linear Cost, Exponential Debt) Control Architecture (Zero Marginal Cost)
New Screen Delivery 2–3 weeks per screen (custom Figma drawing) 1–2 hours per screen (binding schema to existing floorplan)
Component Creation Every new feature invents new UI components 0 new components; 100% mapped to locked AntD floorplans
Engineering Handoff Subjective redlines, ambiguous specs, CSS rework Zero handoff: JSON token schema + deterministic React contracts
Single Architect Leverage Requires 10–15 agency designers to maintain pace 1 Lead Architect governs 350+ screens across 14+ products

Component Topology & Modality Invariants

To prevent structural degradation as hundreds of screens enter the pipeline, we locked strict modality invariants:

  • Modal Dialogs: Restricted strictly to 1–4 inputs for single-intent confirmations (e.g. status transitions, approvals). Multi-step wizards are architecturally forbidden.
  • 2-Row Grid Drawers: Standardized for 5–12 inputs, enabling multi-field parameter entry without obscuring the background ledger.
  • Standard Drawers & Subpages: Utilized for deep sequential entity records and multi-tab dossiers.

05. Platform Topology & Industrial Floorplans

DTCG Token Pipeline & AI-Assisted Compilation

The single source of truth across the 14-product suite is a pure JSON schema (core.json) adhering to Design Tokens Community Group (DTCG) standards. Compiled via Style Dictionary directly into agitoTheme, global tokens propagate across all repositories with zero custom CSS.

To eliminate delivery bottlenecks across simultaneous Product Owner sprints, I engineered an AI subagent compilation pipeline. By feeding actuarial schema rules and floorplan blueprints directly to autonomous subagents, we compile code-ready Ant Design v5 specifications in minutes—enabling a single architect to absorb the upcoming 350+ screen roadmap without quality loss or organizational drag.

“A design system is a control system. Its value is measured not in the volume of components drawn, but in the architectural decisions removed from the table. By locking 4 floorplans and compiling DTCG tokens directly into deterministic React contracts, Agito turned design from an expensive bottleneck into a scalable infrastructure engine.”
